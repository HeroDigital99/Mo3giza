# معجزة — موقع أذكار Static

مشروع واجهة عربية RTL متعدد الملفات باستخدام HTML وCSS وJavaScript وJSON. لا يوجد Backend ولا قاعدة بيانات خارجية.

## التشغيل

من داخل مجلد المشروع شغّل: `python -m http.server 8000` ثم افتح `http://localhost:8000/`. أو ارفع المجلد كما هو إلى استضافة Static. فتح `index.html` مباشرة قد يمنع المتصفح من تحميل JSON بسبب سياسة الملفات المحلية.

## هيكل الملفات
- `index.html`: بنية الصفحة.
- `styles.css`: الألوان الفيروزية، الوضع الداكن، التجاوب والحركة.
- `app.js`: البحث والفلاتر والعدادات والسبحة وتغيير الخط ونسخ النصوص.
- `data/adhkar.json`: نصوص الأذكار والأدعية، أعداد التكرار المقترحة، الفضائل، وروابط المصادر.
- صيغ الصباح والمساء التي يختلف لفظها مفصولة في بطاقات مستقلة، وكذلك دعاء العافية والاستعاذة الملحقة به.
- `CONTENT_REVIEW.md`: ملاحظات توثيق المحتوى وحدود هذه النسخة.
- `validate-data.mjs`: فحص تلقائي لسلامة بنية بيانات الأذكار والروابط.

## ملاحظات تقنية
- الخطوط تُحمّل من Google Fonts عبر الإنترنت، مع خطوط بديلة عند تعذر التحميل.
- الإعدادات والعدادات محفوظة في `localStorage` على الجهاز نفسه. لا توجد حسابات أو مزامنة بين الأجهزة.
- أعداد التكرار في بعض الأذكار إعدادات مساعدة مبنية على الرواية المشار إليها؛ والعدد `0` يعني أن العداد اختياري ولا يوجد عدد افتراضي مخصوص في البطاقة.
- المشروع لم يُنشر على استضافة ولم يُربط بنطاق. هذه ملفات المصدر للتعديل والتطوير.

## توثيق الأذكار والفضائل
- يظهر ملخص فضل كل ذكر داخل البطاقة، ويمكن فتح «الفضل والمصدر» لمراجعة المراجع وحالة التوثيق.
- مصادر كل ذكر محفوظة في `data/adhkar.json` داخل `sourceLinks`، ويمكن إضافة أكثر من رابط عند الحاجة.
- لا تُنسب فضيلة مخصوصة إلى دعاء عام من صياغة الموقع، ولا يُعامل العداد الاختياري كعدد شرعي.
- راجع `CONTENT_REVIEW.md` لمعرفة منهج التوثيق والتحفظات المتبقية.

## الفحص

شغّل `node validate-data.mjs` للتأكد من عدم وجود IDs مكررة أو حقول ناقصة أو روابط غير آمنة.
