# معجزة — الإصدار الأول

مساحة عربية هادئة للقرآن الكريم والأذكار والسبحة الإلكترونية.

## المزايا

- قراءة القرآن الكريم بصفحات واضحة وخط قرآني مناسب.
- اختيار السورة ورقم الصفحة والتنقل بين الصفحات.
- حفظ موضع القراءة وتكبير وتصغير النص.
- أذكار الصباح والمساء والأدعية المختارة.
- سبحة إلكترونية تشمل التسبيح والتحميد والتكبير والاستغفار والصلاة على النبي ﷺ.
- وضع ليلي وخيارات قراءة مريحة.
- تصميم متجاوب للهواتف وأجهزة الكمبيوتر.

## التشغيل

شغّل المشروع من خلال خادم محلي، ثم افتح الصفحة الرئيسية في المتصفح. يمكن نشر الملفات كما هي على أي استضافة مواقع ثابتة.
